BbongGuard

문제

제목과 영상 내용만으로는 주장의 출처나 과장 여부를 확인하기 어렵습니다. 영상을 보던 화면에서 근거까지 볼 수 있게 했습니다.

주요 구현

  • 제목·설명·자막에서 주장을 뽑고 검색 근거를 재정렬해 RAG로 사실관계를 검토합니다.
  • 썸네일 OCR·이미지 분석과 오디오 STT 분석을 보조 신호로 사용합니다.
  • 확장 화면에 요약 판정과 상세 근거를 나누어 보여줍니다. 가짜뉴스·진짜뉴스·비정보성 영상 사례로 동작을 확인했습니다.

문제

피싱 수법을 글로만 설명하면 어느 선택이 위험했는지 실감하기 어렵습니다. 직접 선택한 뒤 결과를 보는 편이 수법을 더 구체적으로 배울 수 있다고 봤습니다.

주요 구현

  • 관리자가 고른 뉴스에서 수법과 상황을 추출해 BFS 방식으로 분기형 시나리오를 생성합니다.
  • 선택에 따라 이야기와 자원 상태가 달라집니다. 끝난 뒤에는 선택 경로를 되짚어 놓친 단서를 보여줍니다.
  • 주요 장면에는 생성한 삽화를 넣었습니다.

문장 유사도

Semantic Text Similarity

한국어 문장 두 개가 의미상 얼마나 가까운지 예측한 모델 실험.

문제

학습 데이터의 유사도 점수가 낮은 구간에 몰려 있었습니다. 이 편향을 줄이기 위해 데이터 분포와 모델 설정을 함께 살폈습니다.

내가 맡은 일

  • 조사 교체와 언더샘플링으로 증강 데이터를 만들고 라벨 분포를 조정했습니다.
  • KR-ELECTRA와 DeBERTa 계열 모델을 실험하고 Optuna 템플릿을 만들어 하이퍼파라미터 탐색에 사용했습니다.

결과

검색 · 질의응답

Open-Domain QA

질문에 맞는 문서를 찾고 그 안에서 답을 추출하는 검색·독해 파이프라인.

문제

검색 결과의 순위와 Reader 설정에 따라 최종 정답률이 달라집니다. 검색 점수를 합치는 방식부터 점검했습니다.

내가 맡은 일

  • Sparse·Dense 검색 점수를 합치는 Hybrid Retriever에 정규화가 빠진 점을 찾아 수정했습니다. 답변 일관성과 EM이 개선됐습니다.
  • Reader 모델과 max_answer_length 등 학습·추론 설정을 비교했고 일부 질문 증강 방식은 검증 데이터와 테스트 데이터의 결과가 달라 채택하지 않았습니다.

Data-Centric NLP

모델은 그대로 두고 문장과 라벨의 오류를 정리해 뉴스 주제를 분류한 실험.

문제

내가 맡은 일

  • DeepL로 한국어→일본어→한국어 역번역 데이터를 만들고 프롬프트 기반 데이터 생성도 실험했습니다.

문제 풀이 모델

Generation for NLP

소형 언어 모델로 수능형 객관식 문제를 풀기 위해 데이터와 프롬프트를 바꿔가며 실험했습니다.

문제

선택지 개수와 정답 분포가 일정하지 않은 데이터를 수능 형식에 맞춰야 했습니다. 긴 지문을 작은 모델이 어떻게 처리할지도 살폈습니다.

내가 맡은 일

  • 모델 탐색, 데이터 증강, 프롬프트 설계와 파인튜닝을 맡았습니다.
  • 문제 생성과 힌트 제공 방식을 비교했습니다. 일부 증강·힌트 실험은 성능 향상으로 이어지지 않아 그 결과도 보고서에 기록했습니다.

결과

일부 데이터 증강과 힌트 방식은 점수가 오르지 않았습니다. 실험 조건과 결과는 보고서에 남겼습니다.
