macOS 앱

Sillog

프로젝트 주제

앱·문서·웹페이지에 흩어진 작업 기록을 업무별로 정리하고 필요할 때 AI가 해당 기록을 찾아 쓰게 하는 macOS 앱입니다.

구현 내용

접근성 API, ScreenCaptureKit, Vision OCR, FSEvents로 활동을 수집합니다. 기록은 로컬 SQLite에 저장하고 업무·세션·자료를 그래프로 연결했습니다. 업무별 기록을 찾아보거나, 채팅에서 연결된 자료를 근거로 답을 받고 파일 결과물을 저장할 수 있습니다.

본인 기여

채팅·프로젝트·플러그인 화면 개발을 맡았습니다. 스킬과 하위 에이전트, 답변 출처·결과물·예약 작업의 동작을 시험하고 있습니다. 플러그인 OAuth 등록과 실제 계정 연결은 아직 검증 전입니다.

현재 상태

개발 중인 프로토타입입니다.

02 / 10KT K intelligence 해커톤 2025

금융 AI 에이전트

Finsight

주최·주관: KT · 대회 주제: KT의 한국어 특화 언어모델 믿:음 2.0을 활용한 B2B/B2G AI Agent 개발

프로젝트 주제

금융권 애널리스트의 기업 조사와 법령 검토를 돕는 AI Agent 시스템 ‘Finsight’입니다.

구현 내용

금융 법령을 검색해 근거와 함께 답변하는 RAG Agent와 기업 분석 보고서를 작성하는 Report Agent로 구성했습니다. 법령의 장·절·조 구조를 보존해 검색하고 기업의 공시·재무제표와 관련 뉴스를 종합해 분석 보고서와 투자 의견을 생성하도록 구현했습니다.

본인 기여

Report Agent 개발을 맡았습니다. DART 공시와 재무제표를 수집·파싱하고 LLM이 기업별 검색 질의를 만들어 뉴스를 수집하도록 구현했습니다. 이후 분석에 필요한 뉴스를 선별하고 재무정보와 결합해 기업 분석 보고서를 작성하는 과정을 자동화했습니다.

Veteran

프로젝트 주제

인터넷 구직 사이트가 낯선 고령자가 전화 상담으로 희망 조건을 전달하고 일자리를 추천받는 서비스입니다.

구현 내용

전화 상담에 STT와 LangGraph 대화 흐름을 적용해 희망 직종·경력·거주지 등을 받습니다. 공공 일자리 데이터에서 맞는 공고를 찾고 상담 기록과 추천 결과를 관리자 화면에 보여줍니다.

본인 기여

프로젝트 주제

구현 내용

구현 내용

본인 기여

4인 팀에서 기사 기반 시나리오 생성부터 분기형 플레이와 사후 피드백까지 이어지는 사용 흐름의 기획·구현에 참여했습니다.

문장 유사도

Semantic Text Similarity

프로젝트 주제

한국어 문장 두 개의 의미 유사도를 0~5점으로 예측하는 모델을 학습했습니다.

구현 내용

학습 데이터의 라벨 분포를 분석하고 문장 교환·조사 교체 등으로 데이터를 증강했습니다. 한국어 사전학습 모델을 파인튜닝하고 모델별 예측을 결합해 성능을 비교했습니다.

본인 기여

낮은 점수 구간에 데이터가 몰린 것을 확인했습니다. 많은 구간은 언더샘플링하고 부족한 구간은 문장 복제·교환·조사 교체로 보완했습니다. KR-ELECTRA와 DeBERTa 계열 모델을 시험하고 Optuna 튜닝 템플릿으로 약 80회 탐색했습니다. 맞춤법·띄어쓰기 교정은 검증 성능이 떨어져 최종 학습에서 뺐습니다.

검색 · 질의응답

Open-Domain QA

프로젝트 주제

질문과 관련된 문서를 찾고 그 안에서 답을 추출하는 한국어 질의응답 모델을 개발했습니다.

구현 내용

Sparse·Dense Retriever로 문서를 찾고 Hybrid Retriever로 검색 점수를 결합했습니다. Reader는 검색된 문서에서 답을 추출하도록 학습시켰습니다. 검색과 독해 설정도 함께 비교했습니다.

본인 기여

Hybrid Retriever의 두 점수를 합산할 때 정규화가 빠진 것을 찾아 수정했습니다. Reader의 max_answer_length·max_seq_length·doc_stride를 비교했고 MeCab을 사용한 질문 증강과 Curriculum Learning 데이터도 시험했습니다. 질문 증강은 검증 데이터와 테스트 데이터의 결과가 달라 채택하지 않았습니다.

뉴스 주제 분류

Data-Centric NLP

프로젝트 주제

모델 구조를 바꾸지 않고 학습 데이터의 문장·라벨 오류를 정리해 뉴스 주제를 분류했습니다.

구현 내용

LLM과 규칙으로 텍스트 노이즈와 라벨 노이즈를 구분해 문장을 정제했습니다. 라벨을 다시 확인한 뒤 Cleanlab, 역번역, 중복 제거를 거쳐 학습 데이터를 구성했습니다.

본인 기여

텍스트·라벨 노이즈 분류와 문장 정제를 맡았습니다. DeepL API로 한국어→일본어→한국어 역번역을 구현했습니다. 작업이 끊겨도 다시 시작할 수 있도록 중간 저장을 넣고 번역 후 특수문자·공백을 정리했습니다. 프롬프트 기반 데이터 생성도 시험했습니다.

문제 풀이 모델

Generation for NLP

프로젝트 주제

소형 언어 모델로 한국어 수능형 객관식 문제를 풀기 위해 데이터와 프롬프트를 실험했습니다.

구현 내용

선택지 수와 정답 분포가 다른 데이터를 수능 형식에 맞춰 정리하고 사전학습 모델을 파인튜닝했습니다. 문제 유형에 따른 프롬프트와 추가 데이터를 바꿔가며 결과를 비교했습니다.

본인 기여

모델 탐색·데이터 증강·프롬프트 설계·파인튜닝을 맡았습니다. KorQuAD 데이터 변환과 LLM의 지문 요약·질문 분석·어휘 해설을 힌트로 주는 방식을 시험했지만 성능이 오르지 않아 사용하지 않았습니다. 여러 프롬프트 형식에 따른 성능 차이도 확인했습니다.
