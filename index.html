문제

동료 평가를 취합하고 보고서로 정리하는 데 드는 반복 작업을 줄이는 것이 목표였습니다. 보고서 생성 시간이 길어 사용자가 결과를 기다려야 하는 문제도 있었습니다.

내가 맡은 일

  • PM으로 일정과 의견을 조율하고, PR 리뷰를 맡았습니다.
  • 백엔드·프론트엔드 가이드라인과 실험용 페르소나 데이터를 만들고, 평가 리마인드와 보고서 자동 발송을 구현했습니다.
  • 도서 정보 처리와 평가서 생성 모듈에서 API 호출을 병렬화하고 SQL 조회를 개선했습니다.

결과

최적화한 두 모듈의 실행 시간을 각각 76.2%, 69.2% 줄였습니다. 서비스 전체 처리 시간이 아닌 해당 모듈의 측정 결과입니다.

문장 유사도

Semantic Text Similarity

두 한국어 문장의 의미 유사도를 예측하는 모델을 학습하고, 라벨 분포와 학습 조건을 검증한 프로젝트.

문제

학습 데이터의 유사도 라벨이 낮은 구간에 몰려 있었습니다. 모델을 바꾸는 실험과 함께 데이터 분포를 조정할 방법을 살폈습니다.

내가 맡은 일

  • 조사 교체와 언더샘플링으로 증강 데이터를 만들고 라벨 분포를 조정했습니다.
  • KR-ELECTRA와 DeBERTa 계열 모델을 실험하고 Optuna 템플릿을 만들어 하이퍼파라미터 탐색에 사용했습니다.

결과

팀 최종 Private Pearson 0.9379, 9위. 개인 단일 모델 점수와 구분한 팀 제출 결과입니다.

검색 · 질의응답

Open-Domain QA

대규모 문서에서 답의 근거를 검색하고, 그 문맥에서 정답을 추출하는 Retriever–Reader 파이프라인.

문제

검색기가 내놓은 문맥의 순위와 Reader 설정이 최종 정답률에 직접 영향을 줍니다. 검색 점수 결합과 답변 길이 설정을 점검했습니다.

내가 맡은 일

  • Sparse·Dense 검색 점수를 합치는 Hybrid Retriever에 정규화가 빠진 점을 찾아 수정했습니다. 답변 일관성과 EM이 개선됐습니다.
  • Reader 모델과 max_answer_length 등 학습·추론 설정을 비교했고, 일부 질문 증강 방식은 검증 데이터와 테스트 데이터의 결과가 달라 채택하지 않았습니다.

결과

팀 최종 Private EM 66.39%, 7위. 검색기 수정 효과와 전체 팀 점수는 별개입니다.

문제

입력 문장과 라벨에 섞인 오류를 그대로 학습하면 모델 변경만으로 해결하기 어렵습니다. 데이터 품질을 높이는 작업에 집중했습니다.

내가 맡은 일

  • 텍스트·라벨 노이즈를 분류하고 문장을 정제하는 과정에 참여했습니다.
  • DeepL로 한국어→일본어→한국어 역번역 데이터를 만들고, 프롬프트 기반 데이터 생성도 실험했습니다.

결과

팀 최종 Private F1 0.8533, 3위. 데이터 정제·증강을 합친 팀 결과입니다.
