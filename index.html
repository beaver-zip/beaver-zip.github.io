Finsight

프로젝트 소개

공시·재무제표·뉴스와 금융 법령을 함께 살펴야 하는 애널리스트의 기업 조사를 돕는 AI 서비스입니다. 대회에서 개발한 서비스를 바탕으로, 대회 이후 개인 프로젝트로 분석·검색·채팅 기능을 개선했습니다.

구현 내용

  • 공시와 재무제표, 시세, 뉴스를 수집해 기업 분석 보고서를 만듭니다. 주요 수치와 차트, 기사 출처를 함께 제공합니다.
  • 법령과 내규를 검색해 관련 조문을 근거로 답변합니다. 채팅에서 기업 분석, 법령 검토, 뉴스 요약을 함께 요청할 수 있습니다.

본인 기여

  • 대회에서 기업 분석 보고서 생성 기능을 맡았습니다. 공시·재무제표·뉴스 수집부터 분석과 차트 생성까지 LangGraph로 연결하고, 사용자가 기사 출처를 확인할 수 있도록 구현했습니다.

대회 이후
개인 개선

  • LLM이 재무 수치를 추출하고 계산하던 방식을 DART API와 Python 처리로 바꿨습니다. 계산값을 보고서 문장에 연결하고 근거 검증과 재작성 단계를 추가했습니다. 16개 기업의 주요 재무 수치를 공시와 대조하고, 검증을 통과하지 못한 문장은 결과에서 제외하도록 했습니다.
  • 법령을 조문 단위로 저장하고 인용·위임 관계를 그래프로 연결했습니다. 키워드·의미 검색과 재정렬에 그래프 탐색을 결합해 시행령과 별표까지 근거를 찾도록 했습니다. 별표의 표 구조를 복원하고 위임 관계를 법령 API와 대조해 검색에 반영했습니다.
  • 질문에 따라 기업·법령·뉴스 작업을 나누고, 필요한 작업을 병렬로 실행한 뒤 근거를 모아 답변하는 채팅 기능을 개발했습니다. 기업명이 모호하면 다시 묻고, 처리 과정과 답변을 실시간으로 표시하도록 구현했습니다.
  • 검색과 답변 품질을 비교할 평가 데이터와 실행 도구를 구성했습니다. 평가 과정에서 발견한 연간 실적 계산 오류를 수정하고, 정정 공시 반영과 문서 교체 실패 시 데이터 보존을 보완했습니다. 회귀 테스트와 프론트엔드 빌드도 GitHub Actions로 자동화했습니다.

피싱 대응 체험 웹 서비스

Scam or Safe

프로젝트 소개

실제 피싱 사례를 선택형 시나리오로 체험하며 대응 방법을 익히는 웹 서비스입니다. 사용자가 내린 선택과 그 결과를 돌아보며 놓친 위험 신호를 확인할 수 있습니다.

구현 내용

  • 기사에서 사기 수법과 피해 상황을 추출해 선택에 따라 전개가 달라지는 시나리오를 만들고, 주요 장면에 삽화를 제공합니다.
  • 체험이 끝나면 선택 경로와 놓친 단서, 더 안전한 대응 방법을 보여줍니다.

본인 기여

  • 한 번의 LLM 호출로 긴 분기 시나리오를 만들기 어려워, Gemini를 장면별로 호출하며 너비 우선 탐색(BFS) 순서로 이야기와 선택지를 확장하도록 설계했습니다. 분기 깊이와 종료 조건은 코드로 관리했습니다.
  • 시나리오가 길어지면 과거 장면은 요약하고 최근 장면과 선택지는 그대로 전달하도록 구성했습니다. 입력 분량을 줄이면서 이전 선택이 후속 장면에 반영되도록 했습니다.
  • Imagen에 공통 인물 정보를 전달해 장면마다 외형을 일관되게 묘사하도록 했습니다. API 호출 제한에 맞춘 배치 처리와 실패한 이미지의 재시도를 구현해 일부 요청이 실패해도 생성을 이어가도록 했습니다.

macOS 업무 기록 앱

실록 (SILLOG)

프로젝트 소개

여러 앱과 웹에 흩어진 사용 기록을 업무별로 정리하고, 이를 바탕으로 답변과 문서를 만드는 macOS 앱을 개발하고 있습니다. 지난 작업에 쓴 자료를 다시 찾고 다음 업무에 활용할 수 있도록 돕습니다.

구현 내용

  • 앱과 웹페이지 사용 내역, 화면 속 텍스트, 다운로드한 파일 등을 자동으로 기록해 기기에 저장합니다.
  • 기록을 업무별로 묶고 관련 자료를 그래프로 연결합니다. 기록에서 당시 사용한 파일과 웹페이지를 다시 열 수 있습니다.
  • 채팅에서 업무 기록과 연결한 서비스의 자료를 함께 활용해 출처가 달린 답변과 문서를 만듭니다. 반복 업무는 사용자가 승인한 일정에 맞춰 실행합니다.

본인 기여

  • 채팅 탭과 외부 서비스 커넥터를 개발했습니다. 선택한 업무의 기록과 문서·코드·협업 서비스의 자료를 검색해 답변에 활용하고, 인용된 출처를 열어 확인할 수 있도록 했습니다. 서비스 인증과 연결 관리, 도구 실행 과정 표시, 대화와 결과물의 버전 관리도 구현했습니다.
  • 외부 LLM에 전달되는 텍스트에서 전화번호·주민등록번호·이메일 등 식별 가능한 개인정보(PII)와 API 키를 가렸습니다. 일반 숫자나 업무 내용까지 잘못 가리지 않도록 정규식과 번호 검증 규칙을 함께 적용했습니다.
  • 캡스톤디자인용 버전에 Laya 기반 로컬 민감정보 분류기를 구축하고 앱에 연동했습니다. 식별자를 가린 뒤에도 남는 민감한 내용을 기기 안에서 판별하고, 해당 기록은 외부 AI 전송과 채팅 검색에서 제외하도록 했습니다.
  • 문서 작성과 조사 등 작업별 스킬에 수행 절차와 결과물 형식을 정의했습니다. Promptfoo로 지시 준수 여부를 평가하고, 프롬프트 수정 전후의 응답을 비교했습니다.
  • GitHub Actions로 PR마다 Swift 빌드·테스트와 앱 번들 실행 검사를 자동화했습니다. 빌드 폴더가 없는 환경에서도 실행되는지 확인해 리소스 누락을 점검하고, main 반영 후 앱 서명·Apple 공증·DMG 배포·Homebrew 설치 정보 갱신을 자동화했습니다. 모델 연결 점검 CLI와 개발 문서도 작성해 팀원이 같은 절차로 빌드·테스트와 문제 점검을 진행하도록 했습니다.

프로젝트 소개

본인 기여

  • 서비스를 기획하고 Chrome 확장 프로그램과 FastAPI 서버를 개발했습니다. 주장 추출, 근거 검색과 재정렬, LLM 판정으로 이어지는 처리 과정과 결과 화면을 구현했습니다.
  • 썸네일 OCR과 음성 분석 결과를 텍스트 검증에 함께 반영했습니다. 사용자가 요약 결과와 상세 근거를 살펴볼 수 있도록 주장별 판정과 참고 출처를 화면에 연결했습니다.

뉴스 주제 분류

프로젝트 소개

모델 구조를 유지한 채 데이터를 정제하고 증강해 뉴스 주제 분류 성능을 개선한 프로젝트입니다. 텍스트 손상과 잘못된 라벨을 구분해 처리했습니다.

구현 내용

  • 손상된 문장을 복원하고 Cleanlab으로 라벨 오류를 교정해 학습 데이터를 정제합니다.
  • 역번역과 LLM 생성으로 표현이 다양한 데이터를 보완하고, 유사한 문장을 걸러 중복을 줄입니다.

본인 기여

  • 텍스트 손상과 라벨 오류를 구분한 뒤, Gemini로 원래 의미를 유지하면서 뉴스 제목을 복원했습니다. 응답에 섞인 설명과 불필요한 기호를 제거하고, 중간 저장과 실패 요청 재시도를 구현해 정제 작업을 이어갈 수 있도록 했습니다.
  • DeepL API로 한국어를 일본어로 번역한 뒤 다시 한국어로 옮겨 표현이 다른 학습 데이터를 만들었습니다. LLM에 주제별 예시를 제공해 뉴스 제목과 라벨을 추가 생성하고, 단어 중복도를 비교해 유사한 제목을 걸러냈습니다.

Open-Domain Question Answering

오픈도메인 질의응답 (ODQA)

프로젝트 소개

질문과 관련된 문서를 검색하고, 해당 문서에서 정답을 추출하는 한국어 질의응답 모델입니다. 문서 검색과 답변 추출을 나눠 성능을 검토했습니다.

구현 내용

  • 단어 일치를 활용하는 BM25와 의미 유사도를 활용하는 Dense Retriever의 점수를 결합해 문서를 찾습니다.
  • Reader가 검색된 문서를 읽고 정답에 해당하는 구간을 추출합니다.

본인 기여

  • BM25와 Dense Retriever의 점수를 결합하는 과정에서 정규화가 빠진 부분을 수정했습니다. 서로 다른 범위의 점수를 같은 범위로 맞춰 문서 순위를 계산하도록 바꾸고, 최종 답변의 정확 일치율(EM)을 비교했습니다.
  • Reader의 최대 입력 길이와 답변 길이, 긴 문서를 나눠 읽을 때 겹치는 범위를 조정하며 성능을 비교했습니다. MeCab으로 질문 데이터를 증강하고, Curriculum Learning 실험에 사용할 학습 데이터를 구성했습니다.

Semantic Text Similarity

문장 유사도 예측 (STS)

프로젝트 소개

한국어 문장 두 개의 의미 유사도를 0점에서 5점 사이의 값으로 예측하는 모델입니다. 데이터 분포와 학습 설정이 예측 성능에 미치는 영향을 비교했습니다.

구현 내용

  • 유사도 구간별 데이터 수를 조정하고, 문장 순서와 조사를 바꿔 학습 데이터를 증강합니다.
  • 사전학습 모델을 파인튜닝하고 여러 모델의 예측을 결합해 성능을 비교합니다.

본인 기여

  • 유사도 0점대에 데이터가 편중된 분포를 확인하고 구간별 샘플 수를 조정했습니다. 동일 문장을 짝지어 높은 유사도 데이터를 보완하고, 문장 순서와 조사를 바꿔 증강 전후의 학습 결과를 비교했습니다.
  • 데이터 로더, 모델, 평가 지표를 분리한 PyTorch 학습 템플릿을 정리했습니다. Optuna로 하이퍼파라미터를 탐색하는 코드를 작성하고, DeBERTa-v3에서 약 80회 실험하며 설정에 따른 검증 성능을 비교했습니다.

산화물 반도체 공정 연구

산화물 TFT 제조 레시피 생성 AI 프레임워크

프로젝트 소개

산화물 TFT의 이동도와 안정성 사이의 상충 관계를 고려해, 목표 성능에 맞는 제조 레시피를 제안하는 연구입니다. 아주대학교 인공지능학과 학부연구생으로 신소재공학과 연구실과의 공동 연구에 참여했습니다.

구현 내용

  • 실험 논문에서 성능과 공정 데이터를 추출하고, 이동도와 안정성을 함께 살펴 고성능 소자의 공정 전략을 정리합니다.
  • 관련 실험 사례를 검색하는 RAG로 레시피를 생성하고, 기존 사례와 비교해 제안한 공정 조건을 평가합니다.

본인 기여

  • 연구팀이 구축한 파이프라인을 적용한 EXAONE-4.0-32B와 기준 모델인 GPT-4.1-nano의 실패 사례를 비교했습니다.
  • 증착 파라미터의 정확도 문제와 희귀 재료에서의 성능 저하를 분석했습니다. 가능한 제조 조건이 여럿인 상황에서 단일 정답과 비교하는 평가 방식의 한계도 정리했습니다.

성과

무역통계 이상탐지

우회수출 위험 품목 상시 감시 프레임워크

프로젝트 소개

공개 무역통계를 바탕으로 우회수출 위험이 있는 품목을 선별하는 분석 프레임워크입니다. 품목별 거래 흐름과 관세 차이를 분석해 추가 확인이 필요한 대상을 좁힙니다.

구현 내용

  • 관세청, 미국 Census, UN Comtrade의 무역통계를 결합해 우회수출에 따른 이익과 국가 간 신고 통계의 차이를 계산합니다.
  • ECOD, Isolation Forest, HBOS의 이상도 순위를 합쳐 의심 품목을 선별하고 월별 분석을 자동화합니다.

본인 기여

  • 공개 무역통계에서 품목별 거래 흐름과 관세 차이를 분석하고, 우회수출 위험을 살펴볼 지표로 정리했습니다.
  • 비지도 이상탐지 결과를 의심 품목 순위와 대시보드로 연결해, 확인이 필요한 품목을 살펴볼 수 있도록 구성했습니다.

성과

장려상 (172팀 중 4위). 4,063개 품목을 분석해 107개 의심 품목과 34개 알림 품목을 선별했습니다.
