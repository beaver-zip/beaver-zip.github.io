금융 AI 에이전트

Finsight

프로젝트 주제

금융권 애널리스트의 기업 조사와 법령 검토를 돕는 AI Agent 시스템 ‘Finsight’입니다.

구현 내용

금융 법령을 검색해 근거와 함께 답변하는 RAG Agent와 기업 분석 보고서를 작성하는 Report Agent로 구성했습니다. 법령의 장·절·조 구조를 보존해 검색하고 기업의 공시·재무제표와 관련 뉴스를 종합해 분석 보고서와 투자 의견을 생성하도록 구현했습니다.

본인 기여

Report Agent를 맡아 DART 공시와 재무제표를 수집·파싱했습니다. LLM이 기업별 뉴스 검색 질의를 만들도록 했고, 수집한 뉴스에서 보고서에 필요한 내용을 골라 재무정보와 결합했습니다. 기업 분석 보고서 작성까지 이어지는 흐름을 자동화했습니다.

macOS 앱

Sillog

프로젝트 주제

앱·문서·웹페이지에 흩어진 작업 기록을 업무별로 정리하고 필요할 때 AI가 해당 기록을 찾아 쓰게 하는 macOS 앱입니다.

구현 내용

접근성 API, ScreenCaptureKit, Vision OCR, FSEvents로 활동을 수집합니다. 기록은 로컬 SQLite에 저장하고 업무·세션·자료를 그래프로 연결했습니다. 업무별 기록을 찾아보거나, 채팅에서 연결된 자료를 근거로 답을 받고 파일 결과물을 저장할 수 있습니다.

본인 기여

채팅·프로젝트·플러그인 화면을 개발했습니다. 채팅에서는 스킬 선택, 답변 출처와 결과물을 확인하는 화면을 만들었고, 하위 에이전트와 예약 작업의 동작을 시험하고 있습니다.

현재 상태

개발 중인 프로토타입입니다.

BbongGuard

프로젝트 주제

유튜브 영상의 주장과 근거를 시청 화면에서 확인할 수 있는 크롬 확장 프로그램입니다.

구현 내용

제목·설명·자막에서 검증할 주장을 뽑고 웹 검색 근거를 재정렬해 RAG로 사실관계를 검토합니다. 썸네일 OCR·이미지 분석과 오디오 STT 결과를 보조 신호로 쓰며 판정 요약과 근거는 확장 프로그램의 두 탭에서 확인할 수 있습니다.

본인 기여

서비스 기획부터 Chrome 확장 프로그램과 FastAPI 서버 구현까지 대부분을 맡았습니다. 영상에서 주장을 뽑고 웹에서 찾은 근거를 재정렬해 판정하는 흐름을 만들었습니다. 썸네일 OCR과 오디오 STT 분석도 연결해 요약·상세 근거 화면에 표시했습니다.

문장 유사도

Semantic Text Similarity

프로젝트 주제

한국어 문장 두 개의 의미 유사도를 0~5점으로 예측하는 모델을 학습했습니다.

구현 내용

학습 데이터의 라벨 분포를 분석하고 문장 교환·조사 교체 등으로 데이터를 증강했습니다. 한국어 사전학습 모델을 파인튜닝하고 모델별 예측을 결합해 성능을 비교했습니다.

본인 기여

라벨 분포를 그려 0점대 문장이 몰린 것을 확인하고, 구간별 목표 개수에 맞춰 언더샘플링과 문장 복제·교환·조사 교체를 적용했습니다. 학습 코드와 설정 파일을 수정해 Optuna 튜닝 템플릿을 만들고 DeBERTa 계열 모델에서 약 80회 실험했습니다.

검색 · 질의응답

Open-Domain QA

프로젝트 주제

질문과 관련된 문서를 찾고 그 안에서 답을 추출하는 한국어 질의응답 모델을 개발했습니다.

구현 내용

Sparse·Dense Retriever로 문서를 찾고 Hybrid Retriever로 검색 점수를 결합했습니다. Reader는 검색된 문서에서 답을 추출하도록 학습시켰습니다. 검색과 독해 설정도 함께 비교했습니다.

본인 기여

Sparse·Dense 검색 점수를 합치는 Hybrid Retriever에서 정규화가 빠진 부분을 찾아 고쳤습니다. 수정 후 답변이 더 일관되게 나오고 EM 점수도 올랐습니다. Reader에서는 답변 길이, 입력 길이, 문서 분할 간격을 바꿔 학습·추론 결과를 비교하고, MeCab 질문 증강과 Curriculum Learning 데이터도 구성했습니다.

뉴스 주제 분류

Data-Centric NLP

프로젝트 주제

모델 구조를 바꾸지 않고 학습 데이터의 문장·라벨 오류를 정리해 뉴스 주제를 분류했습니다.

구현 내용

LLM과 규칙으로 텍스트 노이즈와 라벨 노이즈를 구분해 문장을 정제했습니다. 라벨을 다시 확인한 뒤 Cleanlab, 역번역, 중복 제거를 거쳐 학습 데이터를 구성했습니다.

본인 기여

텍스트·라벨 노이즈를 분류하고 문장을 정제했습니다. DeepL API로 한국어→일본어→한국어 역번역을 구현하면서, 중간 저장을 넣어 작업이 끊겨도 이어서 돌릴 수 있게 했습니다. 번역 결과의 특수문자와 중복 공백을 정리하고 프롬프트 기반 데이터 생성도 시험했습니다.

문제 풀이 모델

Generation for NLP

프로젝트 주제

소형 언어 모델로 한국어 수능형 객관식 문제를 풀기 위해 데이터와 프롬프트를 실험했습니다.

구현 내용

선택지 수와 정답 분포가 다른 데이터를 수능 형식에 맞춰 정리하고 사전학습 모델을 파인튜닝했습니다. 문제 유형에 따른 프롬프트와 추가 데이터를 바꿔가며 결과를 비교했습니다.

본인 기여

모델 탐색과 파인튜닝, 데이터 증강, 프롬프트 실험을 맡았습니다. KorQuAD 문답을 수능형 학습 데이터 형식으로 바꾸고, LLM으로 만든 지문 요약·질문 분석·어휘 해설을 풀이 힌트로 넣었습니다. 형식 지정과 zero-shot CoT 등 프롬프트를 비교했고, 같은 모델에서도 문구에 따라 성능이 0.1 이상 달라지는 경우를 확인했습니다.
